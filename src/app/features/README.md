# `features/`

Route-level application screens. Each page is a standalone component loaded by `app.routes.ts`; feature-local components keep form/card presentation separate from page-level orchestration.

- [`dashboard/README.md`](dashboard/README.md) — overview metrics and quick bookmark creation.
- [`groups/README.md`](groups/README.md) — group list, statistics, CRUD, and fallback reassignment behavior.
- [`bookmarks/README.md`](bookmarks/README.md) — bookmark listing, filters, sorting, and lifecycle actions.
- [`not-found/README.md`](not-found/README.md) — wildcard route display.
