# `features/not-found/`

Fallback page loaded for unknown client routes.

- `not-found.component.ts` — standalone presentation component importing `RouterLink`; it has no local state or business logic.
- `not-found.component.html` — presents a 404 message and a dashboard navigation link.
- `not-found.component.scss` — page-specific styles.
- `not-found.component.spec.ts` — component creation spec.
