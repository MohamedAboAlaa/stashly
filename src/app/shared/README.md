# `shared/`

Reusable presentation and formatting primitives imported by multiple screens. These are standalone Angular components, directives, and pipes.

## Subfolders

- [`components/README.md`](components/README.md) — application navigation and modal shell.
- [`directives/README.md`](directives/README.md) — tooltip and visited-state DOM behavior.
- [`pipes/README.md`](pipes/README.md) — URL-domain and text-truncation transforms.
